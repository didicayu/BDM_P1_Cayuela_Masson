## Implementation

- `ingestion/`: P1 landing and silver ingestion, PCAP replay, Kafka publication
- `trusted/`: P2 Trusted Zone cleaning and rejected-row materialization
- `exploitation/`: P2 Exploitation Zone data products, KPIs, ML anomaly flags, warm-path enrichment
- `consumption/`: analyst-facing CSV, JSON, and HTML exports
- `governance/`: P2 data product catalog, lineage records, and quality metrics
- `models/ids_anomaly_detector/model.json`: trained ML anomaly model artifact generated by the exploitation DAG
- `orchestration/airflow/dags/`: P1 and P2 Airflow DAGs
- `config/`: source configuration
- `tests/`: unit tests for ingestion, replay, P2 zones, consumption, and governance

The delivery archive excludes `.env`, `.venv/`, Docker volumes under `data/`,
Airflow logs, Python caches, LaTeX auxiliary files, and local OS metadata.
