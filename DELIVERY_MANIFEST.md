## Implementation

- `ingestion/`: P1 landing and silver ingestion, PCAP replay, Kafka publication
- `trusted/`: P2 Trusted Zone cleaning and rejected-row materialization
- `exploitation/`: P2 Exploitation Zone data products, KPIs, ML anomaly flags, warm-path enrichment
- `consumption/`: analyst-facing CSV, JSON, HTML exports, and Grafana Postgres serving mirror
- `governance/`: P2 data product catalog, lineage records, and quality metrics
- `models/ids_anomaly_detector/model.json`: trained Isolation Forest metadata generated by the exploitation DAG
- `models/ids_anomaly_detector/model.joblib`: serialized sklearn Isolation Forest estimator
- `orchestration/airflow/dags/`: P1 and P2 Airflow DAGs
- `orchestration/airflow/dags/end_to_end_pipeline_dag.py`: parent DAG enforcing ingestion → warm aggregates → Trusted → Exploitation → Consumption
- `config/grafana/`: Grafana datasource and dashboard provisioning
- `config/`: source configuration
- `scripts/run_p2_local.sh`: deterministic host-side P2 runner with Docker-to-host endpoint translation
- `scripts/build_delivery.sh`: reproducible report and archive builder with integrity verification
- `tests/`: unit tests for ingestion, replay, P2 zones, ML, warm aggregates, Spark configuration, Grafana, consumption, and governance
